한국어

momogram uploader(이하 "앱")는 momogram 채널 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널에 업로드하기 위한 내부 도구입니다. 앱은 YouTube API 서비스를 사용합니다.

  1. 수집·이용하는 정보: 앱은 운영자 본인이 Google 로그인으로 허용한 권한(YouTube 동영상 업로드, 채널 정보 읽기)만 사용합니다. 다른 사용자의 개인정보는 수집하지 않습니다.
  2. 이용 목적: 운영자가 만든 영상과 제목·설명을 운영자 본인 채널에 업로드하고, 업로드 결과(영상 ID·링크)를 확인하기 위해서만 사용합니다.
  3. 저장: Google이 발급한 인증 토큰은 운영자의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.
  4. 제3자 제공: 없습니다. 판매·공유·광고 목적 이용을 하지 않습니다.
  5. 권한 철회: 언제든지 Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 앱의 접근 권한을 철회할 수 있습니다.
  6. YouTube 및 Google 정책: 앱은 YouTube API 서비스를 사용하며, 이용 시 YouTube 서비스 약관(https://www.youtube.com/t/terms)과 Google 개인정보처리방침(https://policies.google.com/privacy)이 적용됩니다.

English

momogram uploader ("the App") is an internal tool used by the momogram channel operator to upload videos they created themselves to their own YouTube channel. The App uses YouTube API Services.

  1. Data accessed: only the permissions the operator grants through Google sign-in (uploading YouTube videos, reading channel information). The App does not collect personal data from any other user.
  2. Use: solely to upload the operator's own videos, titles and descriptions to the operator's own channel and to read back the upload result (video ID and link).
  3. Storage: the OAuth tokens issued by Google are stored only on the operator's computer. They are never sent to an external server or shared.
  4. Sharing: none. Data is not sold, shared, or used for advertising.
  5. Revoking access: access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions
  6. YouTube and Google: by using YouTube API Services, the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) apply.
